# India EPG

Auto-generated XMLTV EPG for Indian IPTV channels. Updated every 12 hours via GitHub Actions.

## Sources
- **JioTV** — 1051 channels
- **Zee5** — 120 channels (Zee TV, &TV, Aaj Tak, NDTV, WION, etc.)

## EPG URL

```
https://GaneshT2305.github.io/india-epg/epg.xml.gz
```

## OTT Navigator Setup

1. Settings → EPG Guide → EPG sources → Add
2. Enter the URL above
3. Set refresh: **12 hours**
4. Match by: **Name** (fallback)

## Schedule

Runs at **05:30 IST** and **17:30 IST** daily.
